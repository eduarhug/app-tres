# Ajedrez Épico

30 niveles de ajedrez: la partida ya está casi terminada y tú das jaque mate (en 1, 2, 3 o 4 jugadas).
Las piezas son personajes animados: el caballo salta, la torre golpea con su martillo, el alfil lanza magia...

Todos los niveles fueron verificados con el motor Stockfish: cada uno tiene mate forzado.

## Compilar el APK
1. Crea un repositorio nuevo en GitHub y sube todo el contenido de esta carpeta (arrastrando).
2. En la pestaña Actions (Comportamiento) se ejecuta "Compilar APK" solo.
3. Al terminar, descarga **AjedrezEpico-apk** en Artifacts, descomprime e instala el .apk.
